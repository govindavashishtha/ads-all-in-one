# Dashboard ↔ API contract notes

Source of truth: `docs/openapi.json` (generated by the API) → `src/lib/openapi.gen.ts`
(`npm run gen:api`). `src/lib/types.ts` only aliases those schemas; `src/lib/api.ts` is the
single module that knows paths, methods and CSRF. When the API changes: regenerate, run
`npm run typecheck`, fix what breaks.

## Conventions the dashboard relies on
- Session cookie `aa_session` (httpOnly); CSRF double-submit cookie **`aa_csrf`** echoed in
  `X-CSRF-Token` on every non-GET. `POST /auth/login` also returns `csrf_token`, kept in memory.
- Money is a JSON string in major units of the account currency (`overview.currency`).
- Not-yet-built logic answers **501** `{detail: {code: "not_enabled", phase: "<n>", message}}`;
  `phase` is a string. 404 is treated the same way for robustness.
- Metric `date` is account-local; hourly `ts_hour` is naive account-local time.
- Approval links: `/ads-autopilot/approvals/{proposal_id}`; the page only reads
  `GET /proposals/{id}`. Decisions are `POST /proposals/{id}/approve|reject` (+ `/approve-batch`).
